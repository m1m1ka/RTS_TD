# 周五保卫战 · Friday Defense

一个 Three.js 格子 RTS + 塔防游戏 Demo。在海岛沙滩上守护美人鱼，击退从不同出生点涌来的海盗。默认六天，每天两波，守住全部关卡即可获胜。

全屏游戏画面，最顶部为当天波次进度条，左右显示核心血条与金币数量。出生点仅保留地面标记；战斗开始后隐藏开始按钮，不显示额外的波次、敌人数和状态文字。底部为四类手牌，等级以与血条数字相同字体的白色 lv 文本显示在英雄单位框左上角，已装备物品图标显示在血条上方。操作说明收进「?」。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

访问终端显示的本地地址。Windows PowerShell 如果限制执行 npm.ps1，请使用 `npm.cmd install` / `npm.cmd run dev`。

```sh
npm run build
npm run preview
```

生产产物位于 `dist/`，可以部署到静态托管服务。字体使用可选的 Google Fonts，网络不可用时回退系统字体；游戏贴图均在本地程序化绘制，没有外部图片依赖。

## 操作和玩法

以下为默认规则；可在独立配置页修改。

- 战斗牌（技能牌）逐张显示，打出后保留并进入独立冷却，卡面显示倒计时，冷却结束可再次使用。默认 1 阶 CD 12 秒；冷却跟随游戏时间与倍速，暂停及商店、奖励、路线选择期间停止，跨波次和跨天保留剩余时间。
- 商店「技能合成」免费将 3 张同名同阶技能牌合成 1 张下一阶技能牌，合成前展示结果；合成保留材料最长剩余冷却。默认最高 3 阶，2/3 阶伤害分别为基础值的 3/9 倍，并提升范围、缩短冷却；百分比伤害最高 100%。在「配置 → 卡牌 → 战斗牌 → 技能冷却与合成」独立配置每阶冷却、伤害、范围、减速和组合效果，可增删阶级（最多 10 阶）。初始手牌、奖励和生成的技能牌从 1 阶开始；临时牌仍遵循当天结束清除规则。

- 点击英雄或 `1–9` 选择；重复点击取消选择，点击目标格自动寻路，`WASD / 方向键` 下达单格移动。英雄和随从可沿八个方向移动，斜向也算一步，途中忽略友军碰撞；选中后点击友军所在格表示移动到该格，到达时占位友军会向周围空格让出一步。没有可让位空格时保留选择并提示；随从让位仍受九宫格限制，炮台让位不会封堵出兵路线。成功下达路线后自动取消选择，单位继续沿路线移动；英雄卡放置后不自动选择。
- 点击英雄、炮台或敌人，左侧显示名字、图标、当前 / 最大生命、攻击力、攻速和攻击距离。攻速保留一位小数，其余为整数；升级、装备和受伤后实时更新。
- 战场默认放大；滚轮以鼠标位置为中心缩放（全图视角的 1～3.2 倍），拖动平移视野，`0 / Home` 返回全图。手机支持单指拖动、双指缩放；轻点仍用于选择和移动。
- 每个关卡拥有独立树木地图，旧关卡默认空地。树木阻挡移动与部署，英雄和随从沿八方向寻路且不穿越障碍拐角，敌人沿四个正交方向寻路。所有单位的攻击距离按八方向格数计算：斜角视为一格，射程 1 可攻击周围八格，射程 2 包含斜向两格；射程提示和武器瞄准遵循同一规则。选中单位时，无边框的半透明绿色格子显示可达位置，包括友军能够让位的格子；排除树木、核心和敌人占据的格子，取消选择时同步隐藏。
- 顶部波次进度条以交叉剑标记每波的起点，从当前节点向下一节点按击杀进度填充；交战中的节点亮起，完成节点变绿。最后一段通向灰色旗帜，当天全部波次完成后旗帜变绿。波次较多时可横向滚动，并自动跟随当前波次或通关旗帜。
- 阿蓝负责近战扛伤，小叶负责远程射击，咕咕的法术对目标相邻敌人造成 55% 溅射伤害。
- 战士挥刀并产生刀光，弓手射出实体箭矢，法师释放魔法弹与爆环，炮台发射咖啡弹，敌军使用爪击。伤害在挥击或弹体命中后结算。
- 单位属性中的「攻击模组」统一为挥砍、爪击、弓箭、弩箭、火枪、法球、咖啡炮 7 类，通过 `attackModule` 配置，不再按英雄列出动作模板。英雄、敌人、炮台共用，外观独立由「实际使用 icon」配置。远程模组自动选择独立武器、转向与弹道；射程、攻速等数值仍单独配置，装备效果可覆盖基础武器。旧配置按原武器与动作自动转换，保留原有表现。随从继承召唤时的攻击模组。
- 所有单位及美人鱼拥有受击闪白、方向性轻震、挤压回弹与命中火花；单位血条带损血拖尾、死亡带淡出动画。法师施法/受击时短暂显现魔法盾（视觉反馈，不额外减伤）。暂停及倍速统一作用于战斗和动画。
- 战场血条使用粗黑框、红色填充与白色生命数字。玩家英雄和炮台常驻显示；敌人受击后显示 2.4 秒，重复受击刷新时间，损血带红条缓降和延迟拖尾，最后淡出。
- 敌人受击产生少量鲜红色溅血；死亡时有短促的定向喷射，致命一击不叠加普通受击溅血。死亡时通过程序化着色器在地面生成鲜红染色，以独立随机种子形成不规则边缘和散落血点，透出沙滩纹理；血迹短暂铺开后持续存在，同格再次死亡会保留旧血迹并叠加新的不规则血泊与血点，逐渐扩大覆盖面积、增加血量；新血迹铺开后合并为每格一张静态贴图，避免持续叠加绘制与闪烁，海上阵亡不生成地面血迹，切换关卡或重开时清除。
- 每个单位有生命、攻击、攻击范围、攻击频率；炮台自动攻击，敌人按各自速度逐格前进。
- 拖拽卡牌至战场使用；也可以先点卡牌，再点目标。无效目标不消耗卡牌，`Esc` 取消选牌。滚轮或左右箭头查看更多牌；拖拽使用绿色虚线贝塞尔箭头指示有效目标，无效目标显示暗红色。
- 英雄牌：在内部空格放置可操控英雄；消耗一张持牌。进入下一天时将上场英雄收回手牌，每位返还一张英雄牌，由玩家重新选择位置部署。等级、阶数、装备和永久加成保留，清除当天临时加成、随从和旧移动路线；阵亡英雄恢复满血后回到手牌，永久销毁或临时英雄不返还。未部署的预备英雄不会重复返还。进入战斗关卡与点击「迎战」时恢复英雄满血；开战效果提高生命上限后也补满。当天波次间不自动回血、复活或清除状态。
- 英雄牌每张独立展示，不显示数量角标。同一种英雄只能上场一位；将重复英雄牌用于场上同名英雄，消耗该牌使其等级 +3，保留装备和当前生命比例，不重复触发上场效果。阵亡等待复活期间不能重复部署或升级。其他卡牌继续堆叠，左上角仅显示「×数量」。
- 猫女「米娅」：初始手牌新增一张，生命 230、攻击 24、射程 1、攻速 1.8、移速 6，使用近战爪击。卡牌 icon 和实际使用 icon 均可选择内置 `catgirl`（猫女 · 米娅）；棋子自动套用青绿色底框。形象由 `src/art.js` 使用与其他英雄一致的几何色块、粗描边绘制，随项目部署，可跨设备导入配置使用。旧配置仅补入一次，后续主动删除或修改会保留。
- 资源牌：实战心得使英雄等级 +1，生命与攻击按该英雄的等级公式成长，并恢复最多 100 生命；升级不会自动增加攻速。热咖啡恢复单个英雄 120 生命；炮台牌放置自动咖啡炮台。炮台不能堵死核心道路。
- 战斗牌：战斗中即时使用。火球对曼哈顿半径 1 内敌人造成 110 伤害；落雷单体 240 伤害；寒霜半径 2、45 伤害，并降低移动速度 55%，持续 3 秒。
- 装备牌：拖到英雄身上永久装备，不重复装备同一物品。鹰眼箭袋攻击 +8 / 射程 +1；疾风徽章攻速 +25%；饮血吊坠攻击吸血 15%；守护护符减伤 25%；星辉法杖替换武器为法杖、射程至少 3，并获得法术溅射。英雄外观不变。
- 持有多少牌就能用多少牌，无能量、抽牌、弃牌或回合出牌次数限制。资源牌与战斗牌用后消耗；英雄和装备从手牌转化为战场上的持续单位或效果。未用的牌跨波次保留。
- 顶部旗帜开始当天，默认等待 3 秒开始第一波。之后每波全员出齐且最后一个敌人死亡即结束，按下一波配置的等待秒数自动开波（默认 5 秒）；出生点还有独立的波内出兵延迟。等待和出兵计时均随暂停、倍速变化。
- 每天最后一波胜利后游戏暂停，从关卡绑定的奖励池按权重抽出三张卡，选择一张后确认收入手牌。可取消选中再选，终点也有奖励。候选卡优先不重复，池中不足三种时重复补足。卡牌依次翻入，选中弹起，确认后飞向手牌，其余卡牌散去。随后展开横向路线图，选择已连接的下一节点，再点击「迎战」。每波结束保留英雄血量、阵亡状态和当天增益；进入下一天（包括商店）时才自动复活、恢复满血并清除当天增益。
- 右上角旗帜可随时查看路线；打开路线图时战斗暂停。默认六天仍按原顺序排列；配置分支后，同一列节点表示同一天的不同路线，可分叉、汇合，通关任一终点获胜。英雄等级、装备、手牌与核心血量沿所选路线保留，跳过的分支不会出兵或发放奖励。
- `空格` 暂停，顶部 `1× / 2×` 调速，可切换合成音效、查看帮助和重新开局。
- 第六天出现「周五临时需求」首领。核心生命归零失败，击退全部 101 名敌人胜利。最佳击退数保存在本机浏览器。

## 金币与暴击

每一天胜利固定获得 4 金币，每座存活金矿额外获得 2 金币，金币沿路线累计、重开清零。最后一波结束后先播放彩带和「胜利」，再在美人鱼上依次竖排显示 4 枚金币，随后在各存活金矿上依次显示 2 枚；动画结束才进入三选一奖励和路线选择。配置页的地图画笔可切换树木／金矿，支持连续绘制和右键擦除，金矿默认 180 生命，可设置绘制生命值。金矿阻挡部署与行走，敌人会接近并攻击，摧毁后留下废墟且不产金币。

新增五张可编辑资源牌及同风格插画，已加入默认奖励池：小金库（获得 3 金币，拖到战场任意位置使用）、再响战鼓（触发目标英雄一次开战及相关监听，不重置波次）、换位思考（与最近存活英雄交换等级）、薪火相传（永久销毁目标及装备，将全部等级交给范围内随机另一位存活英雄）、经验虹吸（吸取 2 格内其他英雄的等级，每人最多 1 级，总计最多 3 级，捐赠者至少保留 1 级）。金币量、作用半径、吸取总上限和每人上限均可配置；范围 -1 表示全场，按格子曼哈顿距离判断。等级转移保留生命比例，等级和金币沿路线保留，销毁的英雄不会在下一天回到手牌。没有有效对象时不会消耗卡牌。

## 林间商店

配置页 →「关卡路线」→ 选择节点 → 将「节点类型」设为「商店」。商店与战斗都占一天，路线图以摊位图标区分；进入后直接购物，不出兵、不触发开战或胜利金币，离开后选择后续路线。进入商店也会收回场上英雄，保留等级、阶数与装备；离开商店不重复返还英雄牌，下一场战斗需要手动重新部署。

- **英雄区**：随机两张英雄牌，普通／稀有／史诗默认分别为 3／5／8 金币。可付费刷新整个英雄区，首次默认 1 金币，每次成功刷新后下次额外增加 1 金币；进入下一家商店重新计数，购买后的空位也会补货。
- **卡包区**：随机两个卡包，类型来自英雄、资源、装备，默认分别 3／2／3 金币。两个卡包各限购一次，刷新英雄不会刷新卡包。购入后播放撕封、光芒和展牌动画，从对应类型随机三张中选一张收进手牌，选完才能离开商店。
- 商品从配置中的对应类型抽取，优先不重复，种类不足时重复补足。价格在「初始默认 → 商店与金币收益」统一配置；商店节点可取消「使用初始默认」后独立配置品质价格、卡包价格与刷新费用，允许 0 金币。余额不足时不可购买或刷新，重复点击不会重复扣费。
- 保存价格实时生效，保存配置不会重新随机库存。已打开卡包中的失效卡牌会剔除；若所有候选均被配置删除则退回该包金币。商店节点、价格和卡牌图像均随 JSON 导出迁移。

英雄、炮台和敌人可配置 0～100% 暴击率，旧配置默认 0%。每次普通攻击独立判定，暴击伤害默认为攻击力的 200%，可通过英雄效果永久提升，再计算减伤；弹道发出时锁定判定与伤害，溅射沿用本次判定，战斗牌不触发单位暴击。升级不自动提高暴击率，装备和触发规则可通过属性效果调整。选中单位显示暴击率，暴击命中显示更大的红色伤害数字。

## 开战机制

「英雄触发牺牲效果后」可监听任意英雄、仅自身或其他英雄，并配置监听距离（-1 为全场）。英雄执行完本次全部已启用的牺牲规则后通知一次；默认情况下，没有启用牺牲规则的死亡不通知；启用下述死亡转牺牲机制时例外。随从死亡始终不通知。只有存活且未销毁的监听者响应，「仅自身」需要先通过牺牲效果复活。监听距离按牺牲发生的位置计算；作用目标「触发事件的英雄」指牺牲者，可搭配复活效果救援。监听效果共用原有连锁防循环机制，不会再次产生牺牲通知。

「复活」效果可搭配「牺牲 → 自身」，默认每天最多 1 次、恢复 50% 最大生命，次数上限和生命比例均可配置。每位目标英雄独立累计，多个复活效果共用该英雄当天的已用次数；同一次死亡最多成功复活一次。换天重置，换波或保存配置不刷新。换波不再自动复活，进入下一天恢复不消耗新一天的技能次数，永久销毁的英雄无法复活。使用其他目标时，复活效果单独筛选范围内阵亡英雄，原格被占用会安置到最近空格；其他效果仍使用原来的目标筛选规则。复活保留等级、装备和有效增益，不重触发整备或开战。

触发时机还支持「牺牲（自身死亡时）」与「胜利（存活至本天战斗胜利）」，可与现有目标、范围及效果组合。牺牲在每次死亡时执行一次，资源牌销毁英雄也会执行；死亡位置用于选取附近存活英雄，随从死亡不触发主人牺牲。自身治疗和升级附带回血不会使阵亡者复活，来源在场增益在死亡期间不生效。胜利仅在当天最后一波清空时由当时存活的英雄各响应一次，阵亡英雄不会因此自动复活；中途清波、失败和商店不触发。当天增益保留到进入下一天时清理，跨天成长应配置永久属性或等级效果。

触发规则新增「范围内所有拥有随从的英雄」目标：触发时选取范围内至少拥有一个存活随从的存活英雄，包含符合条件的自身，效果施加给英雄本人。后续随从死亡或移动不会改变本次已选中的目标。

属性加成可勾选「英雄在场时生效」（默认关闭）：绑定到实际施加效果的英雄实例，来源死亡或离场时立即暂停，复活或重新上场后恢复尚未到期的加成。多来源、装备和未勾选的加成独立保留；「仅当前天」仍按天清除。生命上限下降时当前生命裁切至新上限，恢复上限不会额外治疗。治疗、等级提升、生成卡牌等即时效果不支持回滚；开关只用于持续性属性加成，保存后影响后续触发。

「开战」指玩家点击顶部「迎战」。在倒计时和刷怪之前，依次结算场上存活英雄的开战规则；自动切换波次、部署新英雄、保存配置不会重复触发。

默认英雄规则：

- 阿蓝：开战等级 +1；每有一位英雄触发开战效果（含自身和额外触发），自身移速 +0.5 格/秒。
- 小叶：开战为自身和最近一位其他英雄增加 0.2 次/秒攻速。
- 咕咕：开战额外触发最近一位其他英雄的全部开战规则一次。

等级永久保留，默认攻速和移速加成只持续当前天，当天结束时清除。距离按曼哈顿格数计算，同距离选择更早部署的英雄；阵亡英雄和炮台不参与。每位英雄的正常开战独立发起连锁，同一连锁中每位英雄最多响应一次，避免互相回响无限循环。监听效果本身不会自动生成新的开战事件。

配置页 → 卡牌配置 → 英雄牌 →「触发机制」，可增删、复制、排序、停用规则，或使用四种快捷模板。每条规则独立配置触发事件、事件来源、监听距离、作用目标、目标距离、最近英雄数量和多个后续效果。距离 -1 表示全场；目标支持自身、近邻、自身与近邻、范围内全体英雄和事件来源英雄。效果支持升级、治疗、属性加法/倍率及额外触发，属性加成可选择当天或永久持续。保存只改变下一次触发时使用的规则，不追溯修改已经结算的结果，也不会重复叠加。

旧配置缺少 `triggerRules` 时自动补齐现有三位英雄的默认规则；显式设置空列表表示无规则，会被保留。规则随 JSON 配置导出和迁移。

作用目标可选「范围内随机英雄（含自身）」：设置目标距离（-1 为全场）和随机选取数量（1～20），每次触发从范围内存活英雄中等概率、不重复抽取；人数不足时选取全部。炮台、敌人和阵亡英雄不参与，同一规则的所有后续效果作用于同一批随机目标。

触发机制的「属性加成」支持吸血率，增加数值使用比例（0.1 = 增加 10%），也可乘以倍率；支持仅当前天或永久保留。与装备吸血叠加，最高 95%，按实际造成伤害回复生命，溢出伤害不计入吸血。

恢复生命（触发机制与卡牌效果）和战斗牌伤害可配置「数值类型」：固定值或目标最大生命的百分比，百分比直接填写 10 表示 10%，按生效时每个目标各自的最大生命计算，治疗不超过生命上限。属性加成可选固定值、当前属性的百分比加成或原有倍率；百分比加成填写 20 表示当前属性 × 1.2。没有 `valueMode` 的旧治疗／伤害配置仍按固定值处理。等级与目标数量仍使用整数。

「生成卡牌」可用于英雄触发规则和四类卡牌的组合效果，默认随机生成 1 张资源牌。可选择按类型抽取（英雄／资源／战斗／装备／所有）或勾选候选牌，候选只有一张时固定生成该牌；数量为 1～99，每张独立等概率抽取、允许重复。每个生成效果在一次规则触发或出牌时执行一次，不按英雄目标数或命中敌人数倍增，直接加入手牌并提示，不自动使用或递归触发。保存配置、重算属性和已有英雄跨天重新部署不会重复执行初次出牌生成效果；空类型池不生成，指定候选池需至少一张有效卡牌。切换到指定候选或重新勾选时自动清理已删除的旧卡牌引用；删除卡牌时同步清理组合效果、触发规则和技能各阶中的候选引用，空列表仍需重新选择。

## 规则工坊与配置迁移

英雄牌页新增「英雄形象图鉴」，点击形象即可创建带独立名字、图标、基础属性和推荐武器的可编辑英雄牌：铁壁（重甲坦克）、壳卫（龟甲守卫）、赤鬃（近战狂战士）、竹影（斗笠浪人）、鹰羽（远程游侠）、铜镜（远程炮手）、夜鸦（蒙面刺客）、绯狐（狐族刺客）、霜铃（冰晶法师）、鹿苔（林地祭司）。也可在已有卡牌的卡牌 icon、实际使用 icon 和动作模板中直接选用。新牌需手动加入初始手牌或关卡奖励；外观不绑定远程武器，模板不附带隐藏技能。所有形象由原有 Canvas 绘图体系绘制，配置仅保存内置形象 ID，可随 JSON 跨设备迁移。

游戏右上角的齿轮打开 `/config.html`，配置页和战场可同时打开。

- **卡牌配置**：按英雄、资源、战斗、装备分类，支持新增、复制、删除。名字、描述、卡面 icon 与实际使用 icon 分开设置；PNG / JPEG / WebP 图片会缩放并内嵌进配置。英雄与炮台可配置生命、攻击、攻击距离、攻速、移速和独立武器。
- **效果组合**：升级、治疗、属性增加或倍率、伤害、减速、吸血、减伤、武器替换、攻击溅射、放置炮台。每项效果拥有独立数值；伤害与减速可分别配置作用半径。等级先计入基础成长，再叠加永久属性效果与装备。单次治疗和升级不会因同步而重复触发。
- **英雄触发规则**：与使用卡牌时的即时效果分开编辑，触发事件、监听范围、目标筛选、作用范围与效果数值可自由组合；默认四种开战模板已接入现有英雄。
- **等级公式**：各英雄、敌人独立设置 `levelGrowth.maxHp` 和 `levelGrowth.atk`，按「1 级基础值 + 每级增量 ×（等级 − 1）」计算，再叠加装备或波次倍率。配置页实时预览 1、5、10 级数值。旧英雄继承原全局成长，旧敌人成长为 0。保存时按当前等级重算并保留生命比例，不重复叠加。
- **初始默认**：每天第一波开始等待秒数、初始手牌、核心生命、升级治疗、换天恢复说明和返场英雄复活比例。攻速仅由基础配置与明确的卡牌、装备、触发效果决定。
- **敌人等级**：每个出生点的出兵条目可独立设置等级（1～999，默认 1），同类敌人可以在不同波次、不同出生点使用不同等级。先算等级属性，再乘波次生命 / 攻击倍率并四舍五入；已开始波次的出兵等级保持不变。
- **敌方单位**：新增、复制、删除敌人，配置外观图片、基础属性和武器。
- **天数与波次**：按天管理关卡和胜利奖励，每天支持多波，天和波均可增删、复制、排序。每波配置生命/攻击倍率、上一波结束后的等待秒数。在 15×11 格子图中选择出生点，各点配置波内延迟、逐个出兵间隔、敌人类型及数量列表；总数自动计算。出生点堵住会原地等待，不会换点；仍有未出场敌人时不会提前结算。
- **奖励池**：独立页面新增、复制、删除池，添加候选卡和抽取权重（0 为停用）。各关卡通过 `rewardPool` 引用 `rewardPools` 中的池，可共享或独立配置。被关卡引用的池不能删除，空池不能保存。保存实时影响后续奖励，已展示的有效候选牌保持不变；JSON 导出包含池和关卡绑定。旧卡组奖励自动按卡牌数量合并为对应关卡的权重池。
- **关卡路线**：点击横向图中的节点，编辑该节点全部内容。在「后续路线」勾选一个或多个关卡以连接分支；无后续节点即为终点，可设置路线起点。配置使用 `startDayId` 和各节点的 `next` ID 数组；旧配置缺少连接时按原数组顺序视为直线。保存会拒绝循环、自连、重复、失效连接和孤立节点，导出可跨设备迁移完整路线。
- **地图绘制**：在节点的「当天地图」点击「绘制障碍」，左键按住拖动种树，右键按住拖动连续清除，完成后保存。同一天的全部波次共享 `obstacles` 格子列表，各节点独立。美人鱼和该天出生点不可覆盖，保存时检查道路连通性。实时修改会更新战场并重新寻路；被树木覆盖的单位移到附近空地。空地不足或变更会封堵已经发出的出生计划时，提示保存并重开应用。

- **地图预设**：在「地图预设」页面新建、绘制、命名、复制或删除常用地图，保存树木、金矿位置和金矿生命值。在关卡的「当天地图」选择预设即可套用，也可将当前关卡地图存为预设。套用复制地图布局，保留关卡的波次与出生点；有冲突或道路不通时拒绝套用并说明原因。各关卡与预设独立编辑，修改或删除预设不影响此前已套用的关卡。预设随「保存并同步」及 JSON 导入导出保存，最多 100 个；旧配置自动收录已有的不同地图。

计时示例：第二波设置等待 5 秒，某出生点设置延迟 3 秒。第一波最后一名敌人死亡 5 秒后，第二波开始；再过 3 秒，该点出现第一名敌人，随后按该点间隔依次出兵。敌人配置列表可以混合多种类型，按列表顺序生成。

保存配置后，尚未开始的波次和等待时间同步更新；已经开始波次的出兵计划保持不变，避免重复生成或漏刷。需要立即替换当前波时选择「保存并重开」。单位基础属性、卡牌和装备仍实时同步。

“保存并同步”先校验；通过 `npm run dev` 打开的本地配置页会把游戏规则写入 `public/config/game.json`，再更新浏览器缓存并立即通知同源游戏页面。写入项目失败或检测到其他设备/页面已修改项目文件时，保留草稿并显示错误。已部署单位按当前生命比例更新属性，手牌展示、装备效果与图标、敌人属性和后续生成规则实时更新，未出牌的备战局会同时更新初始手牌。已进行的游戏保留剩余持牌数、升级和消耗记录；“保存并重开”清空当前局并完整应用新初始规则。已经发出的攻击按发射时的数值结算。

**随 Git 同步配置**：配置页保存 → 提交并推送 `public/config/game.json`、`public/config/audio.json`（以及新增的 `public/audio/` 音效）→ 另一台设备 `git pull` 后启动项目或刷新页面。游戏在启动时读取项目配置，旧浏览器缓存不会覆盖拉取到的新版本；被替换的浏览器内容备份到对应 localStorage 键的 `-local-backup` 项。配置保存不会自动执行 Git 提交或推送。游戏文件包含卡牌、内嵌图片、单位、初始手牌、关卡、地图、路线和奖励池；音频文件包含事件绑定及导入音效的实际数据。

构建产物也包含 `config/*.json`，全新浏览器可直接使用这些规则。纯静态部署（包括 `npm run preview`）无法写回服务器或 Git 仓库，页面会明确说明仅保存到本机；如需上传修改，可导出 JSON，在 `npm run dev` 的本地配置页导入并保存，再提交推送。静态部署版本不变时保留本机编辑，项目配置版本更新后优先加载新文件。导入始终先进入草稿，保存后才生效。自动化浏览器测试使用 `FRIDAY_CONFIG_SYNC=0` 禁止改动实际配置；同步集成测试通过 `FRIDAY_CONFIG_DIR` 使用独立测试目录。

配置采用版本 2，支持最多 100 张卡牌、50 种敌人、100 天、每天 100 波，每波最多 40 个出生点和 500 名敌人。版本 1 的本地存档和导入文件自动迁移为「每个旧关卡对应一天、当天一波」，保留敌人数量、类型、出生分配、倍率、卡牌、图片和奖励。保存/导入会校验数值范围、效果枚举、卡牌和敌人引用、可达出生点、初始英雄及图片格式。上传图片单张不超过 5 MB，自动缩小至最长边 256 像素；整份配置限制 3.5 MB，保存失败时保留草稿并可导出备份。

## 实现

**中世纪人物预设**：在配置页「卡牌 → 英雄形象图鉴 → 中世纪军团」可创建灰盔（步兵）、栗骑（骑兵）、燧羽（火枪手）、白棉（医疗兵）、狮旗（指挥官）、长锋（长枪兵）、弩鸦（弩手）、晨祷（牧师）、铁面（行刑官）、赤旌（旗手）。均支持卡牌图标、场上形象和自定义属性；创建预设不改变初始手牌。职业为形象与基础属性模板，治疗等特殊能力可通过触发机制另行组合。新增火枪、弩两种独立远程武器，可切换给任意单位，保留朝向旋转、后坐与实体弹道。

**血誓与狂怒预设**：图鉴新增噬鬃（凶恶狂熊）、赤誓（血誓盾卫）、裂鬃（双斧狂战士）、绯纱（血杯祭司）、缚棘（荆冠殉道者）、暮鸦（赤巾猎手）、烬烛（献火守烛人）、断镣（破枷斗士），图鉴合计 33 个形象。沿用森林绿粗描边、纸片比例与低饱和暗血红配色；可直接选择为卡牌 icon 或实际使用 icon，也可点击创建英雄牌。随附基础属性与攻击模组，技能由配置页自行组合；远程武器保持独立旋转，配置以内置 ID 随 JSON 迁移。

**整备与随从**：英雄牌的「触发机制」可以选择「整备（开战前上场）」，或点击「整备召唤随从」快速添加模板。整备在迎战前放置英雄时触发，每位英雄每天一次；英雄跨天收回手牌，下一天手动重新部署时才重新整备，商店不触发。战斗中部署、换波复活、移动及保存配置不会重触发。整备可组合现有升级、属性、治疗和生成卡牌等效果。「额外触发一次整备效果」会执行目标全部已启用的整备规则，支持现有目标与范围选项，战斗中也可触发，不占用每日正常整备；同一次连锁中，每位英雄最多额外整备一次，整备与开战互相触发也不会无限循环。

随从在主人移动后延迟约 0.4～0.6 秒响应，各随从错开跟随，暂停与倍速同步影响延迟。可点击随从选中，用地面点击或 WASD / 方向键移动；重复点击取消选择，下达有效路线后自动取消选择。活动范围为以主人为中心的 3×3 九宫格，包含四角；高亮与整条手动路线都限制在当前九宫格内。友军占据终点时可以让位，途中的友军可以穿过。手动放置后保持站位，主人移动则延迟跟随；主人走远导致旧路线越界时取消路线并自动归队，归队前不接受范围外手动移动。树木、敌人、核心、金矿和出生点仍不可通行。

「召唤随从分身」可独立选择生命百分比、攻击百分比、数量，也可搭配开战等其他触发时机。数值取目标英雄召唤时的最大生命与攻击力，向上取整；分身采用 65% 体型与小型武器，继承攻速、射程、移速和暴击率，自动跟随攻击，显示独立血条。只在相邻空格生成，避开障碍、单位、金矿、核心及出生点，数量不足则部分生成，全场最多 32 个。随从不继承触发规则和装备附加效果，不计入英雄选择/资源卡目标，死亡不会换波复活，跨天或销毁所属英雄时清除。

**音频配置**：从配置页进入「音频配置」，或直接打开 `/audio.html`。把音效放到 `public/audio/`（支持子文件夹）即可自动发现，开发时每 8 秒更新清单，也可手动扫描；构建时生成音效清单，部署后新增项目文件需重新构建。还可以在页面选择任意本地文件夹或多个文件导入。支持 WAV、MP3、OGG、M4A、AAC、FLAC、WebM，每个文件最多 20 MB，音效库最多 500 个、合计 200 MB。

13 类事件可独立绑定、启停、试听、设置音量与最短播放间隔；保存实时同步同源游戏页面，游戏中点击音符 HUD 开启声音。命中事件只在实际命中时播放。本地开发时音频配置独立写入 `public/config/audio.json`，导入音效的数据随文件迁移，浏览器 IndexedDB 仅用于播放缓存，无需原始文件夹。也可以在音频页导出/导入包含实际音频文件的 JSON 备份。

- `src/art.js`：手绘风 Canvas 贴图、沙滩棋盘、蓝绿色海面与浅水沙岸。
- `src/game.js`：独立战斗模拟、BFS 寻路、卡牌使用校验、装备效果、波次和奖励结算。

**齿轮工坊预设**：图鉴新增螺帽（工程师）、铆钉（重装机器人）、扳手（维修工）、火花（焊接工）、发条（钟芯机器人）。沿用原有 Canvas 粗描边、低饱和森林绿与黄铜色；卡牌图标、场上外观和独立武器可自由配置。

**英雄品质与定位**：英雄牌分为普通（绿）、稀有（蓝）、史诗（金），颜色与品质文字统一显示在手牌、奖励、商店和配置预览中。在「卡牌配置 → 英雄品质与定位」选择品质与坦克、战士、射手、刺客、辅助定位，会自动覆盖基础数值与等级成长，跟随对应预设；技能、外观、攻击模组及治疗行为独立配置。

「初始默认 → 英雄基础数值预设」提供 3 种品质 × 5 种定位共 15 组可编辑数值：基础生命、攻击、移速、攻速、射程、暴击率、生命成长和攻击成长。修改并保存后，所有跟随该预设的英雄同步更新，已部署英雄保留等级、装备与生命比例。初始预设中，稀有和史诗的生命、攻击及其成长分别为普通的 1.25 和 1.6 倍，其他数值可逐项调整。

旧英雄默认补为普通品质、按已有类型和行为推断定位，并保留原数值为「单独配置」。新建英雄自动跟随预设；复制英雄保留原数值来源。切换「单独配置」可以自行编辑属性，重新选择品质、定位或「跟随品质与定位预设」会重新套用预设。预设、品质和定位随配置一同保存和导入导出。运行 `npm run test:hero-grades` 检查页面联动、保存、实战同步和卡面颜色。

**零件与临时牌**：资源牌「零件」可拖到空地建造炮台，复用炮台单位与建造校验，初始 1 级、默认每级生命 +40、攻击 +6，均可配置。卡牌基本信息可勾选「临时牌」，剩余手牌在本天胜利或失败时清除，波间保留，进入下一天也会清除。已经建造的炮台沿用原有跨天保留规则。迁移只添加新牌，不修改已有英雄或初始手牌。

英雄触发机制可快速添加「定时生产零件」和「建造炮台升级」：默认每 10 秒生成 1 张零件，生成种类、数量和间隔均可修改；默认炮台建造时增加自身等级的 50%，向下取整（10 级英雄提升炮台 5 级），可配置监听距离和目标距离。多个存活英雄的建造效果可叠加，失败建造不触发。定时规则从点击迎战开始计时，包含波间等待，死亡清空计时、复活重新累计，换天重置；准备、结算、商店不计时。新触发时机、作用目标和等级比例效果可与其他规则自由组合。

**自动治疗英雄**：配置页「英雄属性 → 战斗行为」可切换「自动攻击 / 自动治疗」。治疗对象可选英雄与随从、仅炮台或全部友军；每次治疗支持固定值或目标最大生命值百分比。治疗频率沿用攻速，治疗距离沿用射程（至少 1 格，斜角计 1 格），移动速度控制追赶速度，已有增益与装备继续生效。治疗不会暴击，生命最多恢复至上限，不治疗自身、阵亡单位、核心或金矿。

也可直接在「英雄属性 → 攻击模组」选择「治疗 · 恢复友军」，自动启用治疗并显示治疗量、类型和目标配置。切回其他攻击模组会恢复自动攻击；旧自动治疗配置会迁移到治疗模组。治疗模组用于英雄，随从继续使用攻击法球。

**战斗数字与受疗特效**：普通伤害统一白字，暴击使用更大的红字，治疗与吸血回复使用绿字。数字带弹出、上浮和淡出动画，密集命中时错开位置。自动治疗会发出绿色方块十字弹，受疗目标身上显示跟随位置的绿色方形光框和上浮十字；资源牌治疗及吸血回复也显示受疗特效。重复治疗刷新光框，特效结束或重开时释放显示对象。

治疗英雄仅在战斗中全图搜索，选择距离最近且能接近的受伤友军，自动走到范围内进行治疗；距离相同按单位入场顺序选择。目标满血、死亡或移动时重新评估，无法接近的目标会跳过。自动移动遵守地形与斜角阻挡规则，可以穿过友军，但不会主动挤开治疗目标。手动移动指令优先，沿途暂停治疗，到达后按新位置重新选取最近伤员。切换行为与治疗参数支持保存后实时生效与配置导出迁移。随从仍沿用原有攻击和主人九宫格跟随机制，不继承主人的自动治疗行为。

治疗施放使用绿色方块十字弹、方形生命光框与原有回血数字；选中治疗英雄时，单位面板显示治疗量、治疗速度和治疗距离。可运行 npm run test:healing 验证配置、实战寻路、手动转移与治疗特效。

**英雄特殊机制（默认无）**：在英雄属性中可独立启用部署后禁移、攻击击退、弓箭减伤和最后生还者苏醒。禁移阻止手动移动、自动追赶与让位，仍可原地攻击/治疗；地图配置强制重新安置与复活安置沿用原规则。击退可配置 1～24 格，普通攻击命中后按出手位置向外推动主目标，斜角为 1 格，障碍、单位、核心、金矿、边界均阻止穿越，不推动尸体或附带溅射目标。箭矢减伤覆盖敌方弓与弩，按实际发射的弹种判定，先通用减伤再扣固定值或百分比，最低可为 0；不影响法球、火枪或近战。

沉睡英雄不能移动、攻击、自动治疗或执行英雄触发规则，仍可受伤、接受治疗与增益。点击迎战后，仅当其他已部署英雄全部死亡或被销毁时苏醒，不统计随从、炮台和手牌；独自参战立即苏醒。先结算队友牺牲复活，再判定苏醒。当天苏醒不会因为队友复活而重置，下一天重新判定；错过的整备、开战事件不补发。沉睡形象变淡，苏醒显示提示。随从不继承这些英雄专属机制。

**胜利奖金**：触发机制快速添加「胜利奖金」，可配置额外金币 1～999。仅搭配「胜利」，需要英雄存活至胜利；每条效果发放一次，不乘以作用目标数量。奖励与基础 4 金币、存活金矿奖励叠加，从获奖英雄上方显示金币后计入总额；大额金币使用数量标记合并展示，避免结算动画无限延长。测试：npm run test:mechanics。

**死亡视为牺牲**：英雄特殊机制新增「所有英雄死亡视为牺牲触发」，默认关闭。任意持有者存活且在场时，全场英雄死亡（含资源牌销毁）都会产生一次牺牲完成事件，无须死者配置牺牲规则。已有牺牲规则照常执行后通知一次，多名持有者不重复计数；仅死者执行自身规则，不额外执行其他英雄的牺牲规则。可搭配「英雄触发牺牲效果后」，沿用监听范围、事件来源与目标筛选，也可通过「触发事件的英雄 → 复活」救回死者。持有者自己的死亡也计入，随后机制失效；复活后恢复，不补发过去死亡。随从、炮台和敌人不计入。此为被动机制，持有者沉睡时仍覆盖死亡，但沉睡英雄不能执行监听规则。配置支持实时保存与迁移。

**用牌英雄效果**：在「卡牌配置 → 英雄 → 触发机制 → 快速添加」选择三个独立模板：每 5 张牌获得随机牌、用牌随机永久强化、资源／战斗牌概率返还。可分配给不同英雄，也可组合使用。

- 每 5 张牌获得随机牌：默认每成功使用 5 张任意牌，从全部卡牌中随机获得 1 张，可配置计数间隔、卡牌类型及随机牌池。
- 用牌随机永久强化：每次成功用牌，等概率选中生命、攻击、吸血、暴击率或暴击伤害之一。默认分别增加 20 生命、2 攻击、1 个百分点吸血、1 个百分点暴击率、5 个百分点暴击伤害，五项增量可独立配置。生命只提高上限，不额外治疗；吸血上限 95%，暴击率上限 100%。永久强化保留至本局结束，升级、复活、换天及保存配置不重复叠加。
- 概率返还：默认使用资源牌后有 20% 概率返还原牌一张；战斗牌触发时清除本张牌的冷却，保留阶级且不增加副本，可配置概率。同一次使用最多返还一次，多个来源不会复制出多张。

仅在英雄存活并在场时响应；准备阶段与战斗中均可触发。自身首次部署不计入自身规则，重复英雄牌升级会计数。计数进度跨波次与关卡保留，死亡期间暂停；修改规则后重新计数。无效出牌、商店购买、奖励、生成和返还均不计为用牌，不会递归触发效果。

**游戏界面**：选中场上英雄后，属性面板右侧显示英雄定位和配置中的卡牌描述，长描述可滚动阅读；移除可移动格子文字提示，右上角仅显示金币统计，保存配置后实时更新。战利品选择去除外层背景框，保留三选一与收牌动画。路线选择为独立全屏森林舆图，路标区分已通过、当前所在、可选与未探索；点击可选节点预览，再点击「踏上征途／前往商店」确认。支持鼠标拖动、触屏滑动及方向键浏览大地图；选择路线期间不能跳过，平时打开舆图可返回战场。

**棋盘外海洋**：棋盘外围采用蓝绿色海面、浅色短波纹和柔和水色层次，沙岸与浅水环绕棋盘。海面纹理缓慢流动，暂停时停止，系统开启减少动态效果时保持静止；棋盘采用深浅交错的浅金沙色地块，点缀少量贝壳、海星与小石子；障碍与放置规则保持原样。

**美人鱼与海盗**：核心替换为珊瑚长发、珍珠冠饰、贝壳座与青绿鱼尾的美人鱼。六种海盗沿用赤鬃与蓝色英雄的粗描边、方块头身和低饱和配色，通过弯刀、火炮、盾牌、药箱、重甲和船长帽区分。配置页「敌方单位 → 海盗形象图鉴」可创建六种可编辑预设，单位 icon 下拉框也可直接换装。旧敌人 ID、已有数值、关卡与自定义图片保留，首次加载补充火炮及医疗海盗预设；本次医疗海盗为形象预设，沿用现有敌方攻击逻辑。奖励卡牌直接浮在战场上，背景不遮挡、不模糊，保留三选一与收牌交互。验证：`npm run test:marine`、`npm run test:rewards`。

**海盗乘船登岸**：敌人按出生点分船，出生延迟控制启航时间，逐个出兵间隔控制靠岸后的登岸间隔。左右岸从左右海面驶入，上下岸从上下海面驶入；船宽固定 1 格、长 4 格，沿航向设 4 个站位，先各站 1 人，多余船员在这 4 个位置上站肩叠起。内陆出生点投影到最近且能通往美人鱼的海岸。每个站位按各自的不可见海面格子计算射程（叠起高度不增加射程距离），航行中双方均可攻击，船员阵亡后自动补位；全部船员在海上被消灭也计入正常波次结算。

「初始默认 → 海盗乘船登岸」提供船航行速度（默认 **2 格/秒**，0.1～20）和登岸击退距离（默认 **2 格**，0～10）。靠岸后可从正前方及沿岸两侧各一格（共 3 格）登岸，优先使用正前方格子，即使有英雄占位也先尝试击退；无法登陆时才选择沿岸两侧空位，跳过障碍和无法通往美人鱼的地块；角落只使用同一岸线上的有效格子。挡路的英雄及随从向岛内击退，即使英雄禁止主动移动也生效；击退途中可越过英雄、随从和敌人，落点被英雄或随从占据时会连带强制腾挪，拥挤阵型支持连续让位；遇障碍、炮台、金矿、核心或边界停止，不能与敌人重叠，不造成额外伤害。所有位移方案确定后再一起执行，无处落脚时不会发生部分击退。0 格禁用击退。三个登岸位置都无法使用时，船员继续留船交战，不与岸上单位重叠；分流登岸仍遵循逐个出兵间隔。设置支持保存后立即生效，暂停和倍速同时影响航行；缩小视野或按 0 / Home 可观察海岸外的船队。测试：`npm test`、`npm run test:sea-arrivals`。

**方块战斗特效**：命中粒子、法术、治疗及护盾由几何正方形拼成，使用清晰像素边缘；刀光与爪击恢复原有弧形攻击，地面血迹采用程序化染色。英雄放置时脚边向两侧扬起白色灰尘，实际移动时留下少量短暂白色灰尘，静止时不产生。升级参考金白光柱与上升箭头：三层阶梯箭头向上浮起，方形轨迹光点绕身，脚下金色方框和细小金色粒子同步淡出；连续升级刷新同组特效，跟随英雄位置。暂停冻结特效，重开及换天清理特效资源。验证：`npm run test:vfx`。

**敌人远程抵挡（默认关闭）**：在「配置 → 敌人 → 特殊机制」勾选「额外抵挡远程英雄伤害」。支持固定数值或 0～100% 抵挡，针对弓箭、火枪、弩和法杖英雄的普通攻击及其溅射；按攻击发出时的弹种判定，装备替换为这些武器也生效，近战、战斗牌、随从与炮台不受影响。暴击和通用减伤结算后，再扣除此机制的减伤，最低为 0，吸血按最终实际伤害计算。实际减伤时显示浅蓝色「抵挡」，部分抵挡仍显示剩余伤害数字，完全抵挡不显示伤害数字。英雄或敌人实际被击退时显示金色「击退」，包括登陆击退及连带让位；没有发生位移则不显示。保存配置会立即更新场上敌人，取消勾选立即移除抵挡。测试：`npm test`、`npm run test:enemy-mechanics`。

**英雄阶数**：英雄初始 0 阶，最高 3 阶，与卡牌品质独立。配置页每位英雄的「英雄升阶」可设置三个递增等级，默认 5／10／15 级。组合效果、触发效果、触发间隔／目标数量／范围、治疗量和可配置特殊机制的数字旁，可分别设置 1～3 阶最终数值；留空沿用 0 阶，旧配置不自动放大效果。等级变化立即重算阶数，支持一次跨多阶及等级交换／吸取后的回落。常驻效果立即更新；历史永久／当天增益保留触发时数值，下次触发读取当前阶数，升阶不补发整备、开战或即时奖励，也不清空生产计时和用牌计数。英雄详情、返还手牌显示阶数，升阶显示飘字。

**经济默认参数**：初始默认可配置普通／稀有／史诗英雄价格（3／5／8）、英雄／资源／装备卡包价格（3／2／3）、首次刷新费用（1）、每次刷新递增费用（1）、每座存活金矿胜利收益（2）及每场胜利固定金币（4），均为 0～999 的整数。刷新费用 = 首次费用 + 当前商店已成功刷新次数 × 递增费用；失败或卡包选择期间不扣费、不增加次数，保存配置不重置次数。战斗关卡最后一波获胜时锁定奖励金额，金币动画按实际金额计入；零收益及大额收益均支持，英雄额外胜利奖金另外叠加。旧商店若使用原默认价格则继承全局设置，自定义价格保留为节点覆盖。测试：npm run test:economy。

**英雄词条说明**：英雄配置中可多选「开战、整备、牺牲、零件」，初始默认中的「英雄词条说明」可统一修改文案（每条最多 180 字）。悬停手牌、战利品或商店英雄卡时，在卡牌上方显示半透明黑底白字说明；无词条不显示。词条仅用于解释，不改变技能机制；旧配置首次载入时按已有效果补上词条。测试：`npm run test:hero-tags`。

**登陆预告**：整备、波次等待和战斗期间，在当前波次尚未出发船只的登陆格外侧海水中显示敌人类型图标，同一登陆点的同类敌人数合并统计；鼠标悬停或键盘聚焦显示名称、数量和类型描述。船只出发后移除其预告，换波自动更新。可在「敌人 → 敌人类型描述（登陆预告）」配置最多 180 字的说明；旧配置兼容，未填写时提示暂无描述。测试：`npm run test:enemy-preview`。

**卡牌出售与交互**：商店新增「出售卡牌」，每次出售一张手中卡牌。普通／稀有／史诗英雄默认售价 1／2／4，战斗／资源／装备牌默认均为 1，可在「初始默认 → 商店与金币收益」配置 0～999 金币。技能牌按具体阶数实例出售，保留其他副本冷却；已培养的待部署英雄单独列出，出售会连同其培养记录和已装备物品一并移除，场上单位不参与出售。选择卡包期间不可出售。出牌失败或取消拖拽后退出卡牌选中；手牌托盘背景透明；阵亡英雄不再阻止选择其他英雄。验证：`npm run test:card-interactions`。

**路线图连线编辑**：配置页关卡路线图支持点击连线选中，再右键该线删除；右键关卡节点进入连线状态，点击下一天亮起的节点创建连接，Esc 取消。断开连接时暂时保留节点列位置，便于重新连接；保存前仍须保证所有节点从起点可达、没有循环。

**英雄上场上限**：最多部署 5 名英雄，右上角金币右侧显示当前人数 / 5。阵亡但尚可复活的英雄继续占名额，永久移除后释放；随从、炮台和待部署英雄不计入。满员时仍可对场上同名英雄使用重复牌升级，第六名英雄部署失败不消耗卡牌。

**测试控制台与升阶描边**：右侧 ⌘ 按钮或 F2 打开测试控制台，打开期间暂停战斗，关闭恢复原暂停状态。可生成任意配置卡牌（每次 1～99 张）、提升已部署英雄等级（每次 1～999 级，总等级不超过 9999），按当前配置重新计算属性与阶数，阵亡英雄不会因调级复活。CRT 扫描线密度、宽度和强度即时作用于场景与 UI，可恢复默认；调试不写入初始配置，画面设置仅在当前页面有效。场上英雄 0 阶保持原样，1 阶蓝色轮廓、2 阶金色轮廓、3 阶流动彩虹轮廓，遵循减少动态效果设置。验证：`npm run test:debug`。

**战斗牌与随从调整**：热咖啡为治疗型战斗牌，默认冷却 12 秒，使用后保留；高阶治疗量及冷却可在卡牌配置中修改。英雄触发效果新增「概率重置本次战斗牌冷却」，可用快捷模板添加并配置概率及各阶数值，只重置刚打出的那一张卡牌。法球不再自带溅射；星辉法杖装备提供显式溅射加成，保留原武器和射程。武器始终绘制在人物上层。随从可生成于主人周围八格，每位英雄最多 8 名存活随从，障碍或占位仍会限制生成。验证：`npm run test:combat-content`。

**英雄详情与商店奖励池**：英雄信息框按普通／稀有／史诗使用绿／蓝／金色。英雄配置「英雄升阶」可填写 0～3 阶描述，场上信息面板按当前阶数显示，留空沿用基本描述。关卡配置中，商店节点可分别为英雄商品和三类卡包选择现有奖励池；沿用权重并筛选同类卡牌，未选择则使用全部同类卡牌。引用池须含有效同类卡牌，被商店引用的池不能直接删除。
